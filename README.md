# AFIN Web

Презентационный сайт платформы [AFIN](https://github.com/Dr0wsyC0der/afin-ui-backend) (на сайте продукт представлен под брендом FLOWSMB): моделирование, симуляция и анализ бизнес-процессов с ML-прогнозом задержек.

**HTML** • **CSS** • **JavaScript** (без фреймворков и сборки)

## Страницы

| Файл | Содержание |
| --- | --- |
| `index.html` | Главная: ценность продукта и основные возможности |
| `product.html` | Описание платформы и её архитектуры |
| `solutions.html` | Отраслевые решения, переключение по вкладкам |
| `cases.html` | Примеры использования |
| `about.html` | О команде |
| `contacts.html` | Контакты и форма обратной связи |
| `privacy.html`, `terms.html` | Политика конфиденциальности и пользовательское соглашение |

`style.css` — общие стили и адаптивная вёрстка, `script.js` — плавная прокрутка к якорям, подсветка активного пункта меню, мобильное меню, вкладки и обработка формы на стороне клиента (без отправки на сервер).

## Запуск

Откройте `index.html` в браузере или поднимите локальный сервер:

```bash
python -m http.server 8080
```

и перейдите на <http://localhost:8080>.
